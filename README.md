# 神速伶伦 2.0

一款使用 **Cocos Creator 3.8.6 + TypeScript** 制作的五键下落式音乐节奏游戏。
音符沿五条轨道下落，在穿过判定线时按下对应按键，按准确度获得判定、分数与连击加成。

> 当前进度：挑战模式三关可完整游玩；剧情模式开发中。

---

## 玩法

- 音符从屏幕上方下落，穿过判定线时按下对应轨道的按键
- 判定依据是**音符中心到判定线的像素距离**（判定线 y = -300）：

| 判定 | 距离 | 基础分 |
| --- | --- | --- |
| Perfect | ≤ 10 px | 100 |
| Great | ≤ 30 px | 60 |
| Good | ≤ 80 px | 30 |
| Miss | > 80 px，或越过判定线未击打 | 连击归零 |

- 连击倍率：10 连击 ×1.5，20 连击 ×2.0
- 单局漏掉 10 个音符即失败；时间结束且总分 ≥ 1000 视为通关
- 最高分与上次得分按关卡分别存入本地

## 操作

| 按键 | 轨道 |
| --- | --- |
| `A` | 第 1 轨（最左） |
| `S` | 第 2 轨 |
| `D` | 第 3 轨（中间） |
| `J` | 第 4 轨 |
| `K` | 第 5 轨（最右） |

右上角齿轮用于暂停 / 继续，暂停菜单内可拖动滑条调整 BGM 与打击音效音量。

## 关卡

| 关卡 | 时长 | BPM | 谱面密度 |
| --- | --- | --- | --- |
| 第一关 | 90 s | 120 | 三段式：每 2 拍 → 每 1 拍 → 每 2 拍 |
| 第二关 | 100 s | 141 | 全程每 1 拍 |
| 第三关 | 180 s | 141 | 暂与第二关一致 |

## 技术要点

- **音符对象池**：音符全部通过 `NodePool` 复用，避免高频 `instantiate` / `destroy` 引起的 GC 抖动。音符被回收时约定调用 `reset()` 复位状态（缩放、旋转、扇翅相位），保证复用的对象与新建的一致。
- **判定用距离而非时间戳**：距离 = 速度 × 时间差，两者等价，但距离只需一次减法即可比较，判断成本更低。音符位移由 `deltaTime` 驱动，因此判定与帧率无关。
- **谱面按 BPM 程序化生成**：以「到达判定线的时刻」为基准，向前推一个下落时间 `fallTime` 作为生成时刻，使音符落到判定线时正好卡在拍点上。
- **统一的场景切换**：所有跳转经由 `LoadingController.goto()`，中转场景负责过渡动画，并用 `static` 成员跨场景传递目标场景名。
- **本地存档**：使用 `sys.localStorage` 按 `level{n}_best` / `level{n}_last` 两个键分别保存最高分与上次得分。

## 项目结构

```
assets/
├── scenes/        8 个场景：Start / Loading / MainMenu / Intro / LevelSelect / Game / Game2 / Game3
├── scripts/       15 个 TypeScript 组件（玩法、UI、动画、工具）
├── prefab/        Note.prefab —— 音符预制体
├── resources/
│   ├── audio/     三关 BGM + 五声音阶打击音色（C4 / D4 / E4 / G4 / A4）
│   └── effects/   光点粒子贴图
├── textures/      背景、UI、人物与插图
└── fonts/         霞鹜文楷 LXGWWenKai-Medium
```

设计分辨率 **1920 × 1080**，适配模式 fit width。

## 运行方式

1. 使用 Cocos Dashboard 导入本目录
2. 打开 `assets/scenes/Start.scene`
3. 点击预览（或 `Ctrl + P`）

需要 **Cocos Creator 3.8.6**。键盘操作，请使用浏览器预览或桌面端构建。

## 已知限制

- 谱面为程序化生成，尚无谱面文件与谱面编辑器，因此暂不支持长按、变速等进阶音符
- 第三关谱面暂与第二关相同，尚未做独立难度设计
- 轨道坐标按 1920 × 1080 设计分辨率写死，未做多分辨率下的轨道间距自适应
- 存档仅记录分数，尚未保存关卡解锁状态与设置项
