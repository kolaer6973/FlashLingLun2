# 神速伶伦 2.0

一款使用 **Cocos Creator 3.8.6 + TypeScript** 制作的五键下落式音乐节奏游戏，并带有完整的剧情模式（视觉小说式对话 + BOSS 战）。

音符沿五条轨道下落，在穿过判定线时按下对应按键，按准确度获得判定、分数与连击加成。

> 当前进度：挑战模式三关可完整游玩；剧情模式第一章（含两场 BOSS 战）已完成。

---

## 玩法

- 音符从屏幕上方下落，穿过判定线时按下对应轨道的按键
- 判定依据是**音符中心到判定线的像素距离**（判定线 y = -300）：

| 判定 | 距离 | 基础分 |
| --- | --- | --- |
| Perfect | ≤ 10 px | 100 |
| Great | ≤ 30 px | 60 |
| Good | ≤ 80 px | 30 |
| Miss | > 80 px，或越过判定线未击打 | 连击归零 |

- 连击倍率：10 连击 ×1.5，20 连击 ×2.0
- 单局漏掉 10 个音符即失败；时间结束且总分达标视为通关
- 最高分与上次得分按关卡分别存入本地

## 操作

| 按键 | 轨道 |
| --- | --- |
| `A` | 第 1 轨（最左） |
| `S` | 第 2 轨 |
| `D` | 第 3 轨（中间） |
| `J` | 第 4 轨 |
| `K` | 第 5 轨（最右） |

右上角齿轮用于暂停 / 继续，暂停菜单内可拖动滑条调整 BGM 与打击音效音量。

## 技术要点

- **音频节拍对齐**：用 Python 对每首 BGM 做谱通量（spectral flux）分析 + 网格拟合，测出**真实 BPM** 与**首拍偏移**（实测偏差 0.01–0.41 秒）。若直接按标称 BPM 从 0 秒排谱，一首 90 秒的曲子末尾会累积接近 1 秒的偏移，判定与音乐完全对不上。排谱时以实测拍点网格 `offset + k × beat` 为锚点，误差不随曲长累积。
- **难度按音符间隔分档，而非按 BPM**：同样「每拍一个音」，87 BPM 是 690 ms（松），148 BPM 是 405 ms（紧）。改为先定目标间隔（0.42 s / 0.28 s），再在四分 / 八分 / 十六分里选最接近的音符时值，使不同速度的曲子手感一致。
- **音符对象池**：音符全部通过 `NodePool` 复用，避免高频 `instantiate` / `destroy` 引起的 GC 抖动。回收时调用 `reset()` 复位状态（缩放、旋转、扇翅相位）。
- **判定用距离而非时间戳**：距离 = 速度 × 时间差，两者等价，但距离只需一次减法即可比较。音符位移由 `deltaTime` 驱动，判定与帧率无关。
- **剧情系统**：自研 `DialogueBox` 组件，支持逐字显示、点击推进、立绘按角色切换、插画保持至下一张；`StoryData.ts` 以数据驱动方式存放 8 段剧本共 367 句台词。
- **流程状态机**：`StoryFlow` 管理「黑屏旁白 → 自由探索 → 剧情点触发 → BOSS 战 → 结算」；剧情点用 `StoryPoint` 组件复用（点击 → 寻路到落脚点 → 按进度播不同剧情）。
- **BOSS 场景复用**：所有剧情 BOSS 战共用同一个 `Boss.scene`，通过 `BattleConfig` 在切换前注入 BGM / BPM / 背景 / 难度 / 判定标识，避免为每场战斗复制场景。
- **统一的场景切换**：所有跳转经由 `LoadingController.goto()`，中转场景负责过渡动画，用 `static` 成员跨场景传递目标场景名。
- **本地存档**：使用 `sys.localStorage` 按 `level{n}_best` / `level{n}_last` 分别保存最高分与上次得分。

## 项目结构

```
assets/
├── scenes/        10 个场景
│                  Start / Loading / MainMenu / Intro / LevelSelect
│                  Chapter1（剧情）/ Game / Game2 / Game3 / Boss（BOSS 战通用）
├── scripts/       30 个 TypeScript 组件
│                  玩法（GameController / Note / PlayerController）
│                  剧情（StoryFlow / StoryPoint / DialogueBox / BlackNarration / StoryData）
│                  系统（LoadingController / BattleConfig / ChapterProgress / SceneBgm）
├── prefab/        Note.prefab —— 音符预制体
├── resources/
│   ├── audio/     12 个音频：10 首 BGM + 判定音 + 漏音
│   ├── cg/        11 张剧情插画
│   └── effects/   光点粒子贴图
├── textures/      地图、角色、立绘、UI、图标
└── fonts/         霞鹜文楷 LXGWWenKai-Medium
```

设计分辨率 **1920 × 1080**，适配模式 fit width。

## 运行方式

1. 使用 Cocos Dashboard 导入本目录
2. 打开 `assets/scenes/Start.scene`
3. 点击预览（或 `Ctrl + P`）

需要 **Cocos Creator 3.8.6**。键盘操作，请使用浏览器预览或桌面端构建。

## 已知限制

- 谱面为程序化生成，尚无谱面编辑器，因此暂不支持长按、变速等进阶音符
- 剧情模式目前只完成第一章，后续章节尚未接入
- 进度（章节完成状态）只存在内存中，关闭游戏后重置，尚未接入本地存档
- 轨道坐标按 1920 × 1080 设计分辨率写死，未做多分辨率下的轨道间距自适应
